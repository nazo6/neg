# neg

> [!WARNING]
>
> negは完成しておらず、まだ使うことはできません。以下には開発中の内容が含まれます。

negはKeyballにインスパイアされたトラックボール搭載の分割キーボードです。

## 特長

negは機能面で妥協をすることなく、消費電力を可能な限り抑え無線で使用できるようにすることを目標としたキーボードです。現在はKeyball61を基にした「negL」を開発中です。
主な特徴は以下の通りです。

- nrf52840搭載ProMicro互換ボードのnice!nanoを使用
- 高精度かつ低消費電力なPAW3395マウスセンサーにより、25mmトラックボールを搭載可能
- EVQWGD001 水平ロータリーエンコーダを搭載
- SSD1306 OLEDディスプレイを取り付け可能
- SK6812MINI-E RGB LEDを取り付け可能
- 通常の単三電池あるいは14500電池が使用可能
- 一部カラムスタッカード配列を採用

### 主じゃない特徴

- LEDへの電力供給にスイッチを付けることでLEDの待機電力消費を防止可能(SK6812MINI-Eは待機時でも一つあたり1mAほどの電力消費があります。)
- さらにLEDの電力供給部にはMOSFETを搭載しており、nice!nanoであれば通常のProMicroには存在しない追加の3ピンを用いてソフトウエアからLEDのON/OFFを操作可能
- トラックボール基盤部はなるべくKeyballと互換性を持つように設計されており、Keyballのトラックボール基盤及びトラックボールケースが使用可能(要検証)
- TRRSケーブルによる有線左右間通信が可能(全二重通信を採用しており、TRSケーブルは使用できません。)
- シフトレジスタの74HC595を用いてDuplex
  Matrixではなく通常のマトリックスを使用可能に。これによりゴーストの軽減やより消費電力を抑えたスリープ機能の実装などが期待できます。

### マイコンについて

negではnice!nanoというボードを採用していますが、これには技適が通っていないという重大な問題があります。
将来的にBLE Micro Proが使えるかどうかを検討する予定です。

## 必要部品

- 部品: 部品概要
- 部品名: 型番など
- 実装: JLCPCBのPCBAで実装できるかどうか
  - ○: Basicパーツで実装可能
  - △:
    実装可能ではあるがExtendedパーツであるなどのの理由で基本的に実装されていない
  - X: 実装不可
  - -: 実装対象ではない
