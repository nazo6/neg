# neg

> [!WARNING]
>
> negは現在開発中です。動作の保証は一切ありません。

negはKeyballにインスパイアされたトラックボール搭載の分割キーボードです。

## 特長

negは消費電力を可能な限り抑えて無線に対応しながらも機能面で妥協せずにLEDやディスプレイなどの高度な機能を使用できるようにすることを目標として開発中です。

### 主な特徴

- nrf52840搭載ProMicro互換ボードのnice!nanoを使用
- 高精度かつ低消費電力なPAW3395マウスセンサーを搭載
- EVQWGD001 水平ロータリーエンコーダまたはEC12ロータリーエンコーダを搭載可能
- SSD1306 OLEDディスプレイを搭載可能
- SK6812MINI-E RGB LEDを搭載可能
- 最低1.2Vから動作し単三電池、14500電池、LiPo電池またはUSBからの給電が可能
- 14500電池、LiPo電池の充電が可能
- 一部カラムスタッカード配列を採用

### 主じゃない特徴

- LEDへの電力供給にスイッチを付けることでLEDの待機電力消費を防止可能(SK6812MINI-Eは待機時でも一つあたり1mAほどの電力消費があります。)
- さらにLEDの電力供給部にはMOSFETを搭載しており、ソフトウエアからLEDのON/OFFを操作可能
- トラックボール基盤部はなるべくKeyballと互換性を持つように設計されており、Keyballのトラックボール基盤及びトラックボールケースが使用可能(要検証)
- TRRSケーブルによる有線左右間通信が可能(全二重通信を採用しており、TRSケーブルは使用できません。)
- シフトレジスタの74HC595を用いて通常のマトリックスが使用可能。これによりゴーストの軽減やより消費電力を抑えたスリープ機能の実装などが期待できます。

### マイコンについて

negではnice!nanoというボードを採用していますが、これには技適が通っていないという重大な問題があります。BLE
Micro Proとの互換性について検証中です。

### ジャンパについて

回路(の主に電源周り)について様々なパターンを検証するために多数のジャンパを設けています。それぞれのジャンパの説明は以下のようになります。

#### 電源系

- JP1:
  電池ホルダーとマイコンのBATピンを直結します。14500電池を入れる場合に使用します。
- JP2:
  電池ホルダーからの電源を3.3Vに昇圧します。単三電池を入れる場合に使用します。
- JP3:
  このジャンパが未接続の場合、電池回路にはダイオードが接続されており、充電電流が流れるのを防止しています。このジャンパを接続することによりダイオードの両端子がショートし逆電流が流れるようになります。
  必ず**接続している電池がLiPo電池かLi-ion電池である場合にのみ**このジャンパを用いて充電を有効にしてください。つまり、JP2接続時にJP3を接続するべきではありません！

#### キースキャン

- JP4:
  COL0とROW3を接続します。ソフトウエアで左右を判定するのに用いることを想定しています。

#### TRRS

- JP5-8:
  JP5,6とJP7,8がそれぞれペアになっており、このペアのどちらかを両方繋ぐことによりTXとRXピンを反転させることができます。ただしnrf52840ではソフトウェアでRXとTXを反転させることができるのでJP5,6を使用すれば大丈夫なはずです。

#### LED

- JP9:
  LEDのVCCを5Vに昇圧します。SK6812MINI-Eは仕様上3.3Vでは動作しないためこの回路を設けていますが、実際には3.3VのVCCでも動作してしまうため、無効化できるようになっています。
- JP10:
  マイコンのLED_POWERピンとスイッチを接続し、ソフトウェアからLEDへの電力供給を遮断することができるようになります。**5V昇圧時(JP9接続時)にのみ有効化してください！**
- JP11: LED
  VCCの5V昇圧回路を無効にします。この機能はデバッグ目的であり、このモードを有効にするとスライドスイッチに直接LED電源電流が流れる、LED_POWERピンが使用できなくなるといった制限が課されます。
- JP12: **LED制御信号の**5V昇圧回路を無効にします。
- JP13: **LED制御信号の**5V昇圧回路を有効にします。

NOTE:
これらのジャンパは5V昇圧を有効にする場合は「JP9,JP10,JP13」無効にする場合は「JP11,JP12」というペアで使用することを想定しています。

# 注意事項

- 機能を切り替えるジャンパは排他的です。かならず適切なジャンパのみをはんだ付けしてください。適切に機能しなくなったり、最悪の場合故障する可能性があります。
- 特にJP3について、**必ず**「対応した充電池を使用しており昇圧回路が有効になっていない場合にのみ」有効にしてください。さもないと発火や爆発などの危険があります。
