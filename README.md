# neg

> [!WARNING]
>
> negは現在開発中です。動作の保証は一切ありません。

negはKeyballにインスパイアされたトラックボール搭載の分割キーボードです。

## 特長

negは消費電力を可能な限り抑えて無線に対応しながらも機能面で妥協せずにLEDやディスプレイなどの高度な機能を使用できるようにすることを目標として開発中です。

### 主な特徴

- nrf52840搭載ProMicro互換ボードのnice!nanoを使用
- 高精度かつ低消費電力なPAW3395マウスセンサーを搭載
- EVQWGD001 水平ロータリーエンコーダまたはEC12ロータリーエンコーダを搭載可能
- SSD1306 OLEDディスプレイを搭載可能
- SK6812MINI-E RGB LEDを搭載可能
- 最低1.2Vから動作し単三電池、14500電池、LiPo電池またはUSBからの給電が可能
- 14500電池、LiPo電池の充電が可能
- 一部カラムスタッカード配列を採用

### 主じゃない特徴

- LEDへの電力供給にスイッチを付けることでLEDの待機電力消費を防止可能(SK6812MINI-Eは待機時でも一つあたり1mAほどの電力消費があります。)
- さらにLEDの電力供給部にはMOSFETを搭載しており、ソフトウエアからLEDのON/OFFを操作可能
- トラックボール基盤部はなるべくKeyballと互換性を持つように設計されており、Keyballのトラックボール基盤及びトラックボールケースが使用可能(要検証)
- TRRSケーブルによる有線左右間通信が可能(全二重通信を採用しており、TRSケーブルは使用できません。)
- シフトレジスタの74HC595を用いて通常のマトリックスが使用可能。これによりゴーストの軽減やより消費電力を抑えたスリープ機能の実装などが期待できます。

### マイコンについて

negではnice!nanoというボードを採用していますが、これには技適が通っていないという重大な問題があります。BLE
Micro Proとの互換性について検証中です。

## 必要部品

> [!NOTE]
>
> PCB上にある部品のうち、必要部品に無い物は全てPCBAではんだ付けすることを想定しています。
>
> LCSC情報が埋め込まれているため、KiCadの[kicad-jlcpcb-tools](https://github.com/Bouni/kicad-jlcpcb-tools)を用いることで簡単にJLCPCB用データをエクスポートできます。
>
> なるべくBasic及びPreferred Extendedのパーツを使用するようにしていますが、
>
> - メインPCB基板では昇圧モジュールTLV61070A
> - トラックボール基板では一部の抵抗とコンデンサ
>
> がExtendedパーツになっています。

### ジャンパについて

回路(の主に電源周り)について様々なパターンを検証するために多数のジャンパを設けています。それぞれのジャンパの説明は以下のようになります。

> [!IMPORTANT]
>
> - ある機能に対して複数のジャンパが指定されている場合、それらのジャンパ全てを接続することにより機能が有効になります。
> - 機能を切り替えるジャンパ(昇圧するかしないかなど)は排他です。必ず適切なジャンパのみをはんだ付けしてください。適切に機能しなくなったり、故障する可能性があります。

#### 電源系

- JP1:
  このジャンパを接続することにより電源回路への充電電流を防ぐダイオードを無効化し、充電を有効化します。有効化する際は必ず以下の注意事項を守ってください。

> [!CAUTION]
>
> このジャンパを接続していいのは以下の条件を全て満たしているときのみです。
>
> - 接続しているのが充電池であり、さらにそれはLiPo電池かLi-ion電池である(ニッケル水素充電池は不可)。
> - JP2かJP3の**どちらか一方のみ**を有効化しており、更に昇圧回路(JP4,JP5)を有効化していない。
> - 使用しているマイコンが適切な充電機能を有している
> - バッテリーに保護回路が組み込まれている
>
> これらの条件に違反するとバッテリーが発火したり爆発するおそれがあります。

- JP2: LiPoコネクタを有効化します。
- JP3:
  電池ホルダーとマイコンのBATピンを直結します。14500電池を入れる場合に使用します。
- JP4,JP5:
  電池ホルダーからの電源を3.3Vに昇圧します。単三電池を入れる場合に使用します。

#### キースキャン

- JP6:
  キーマトリックスのCOL0とROW3を接続します。ソフトウェアで左右を判定するのに用いることを想定しています。

#### TRRS

- JP7,8: TRRSジャックを有効化します。通常は常にこれを接続してください。
- JP9,10:
  こちらもTRRSジャックを有効化しますが、通信の極性を反転させます。RP2040でUARTを使用するテストのためのもので通常は使用する必要はありません。

#### LED

- JP11,JP12: **LED制御信号の**5V昇圧回路を無効にします。
- JP13: **LED制御信号の**5V昇圧回路を有効にします。
- JP14:
  **LED電源の**5V昇圧回路を無効にします。SK6812MINI-Eは仕様上3.3Vでは動作しないため5Vへの昇圧回路を設けていますが、実際にはそれよりも低い電圧で動作するため、動作を切り替えられるようにしています。
- JP15,JP16: **LED電源の**5V昇圧回路を有効にします。

> [!IMPORTANT]
>
> 制御信号と電源の電圧を揃えるようにしてください。
> つまり、LEDの5V昇圧を有効にする場合は「JP13,JP15,JP16」、無効にする場合は「JP11,JP12,JP14」を接続します。

> [!NOTE]
>
> 5V昇圧有効時と無効時ではLED電源切り替えスイッチの極性が反転します。
